# ROVELLE | Luxury Sculpt & Shapewear Maison

A high-performance luxury shapewear e-commerce boutique modeled after [houseofrovelle.com](https://houseofrovelle.com). Built with **React 19**, **Vite**, **TypeScript**, **React Compiler**, and **ESLint**.

---

## 🚀 Key Features

* **Luxury Editorial Design:** Warm neutral and earthy color palette (Onyx, Nude Almond, Warm Mocha, Cocoa), refined typography (Playfair Display + Plus Jakarta Sans), and smooth micro-interactions.
* **React Compiler Enabled:** Configured with `babel-plugin-react-compiler` and `eslint-plugin-react-compiler` for automatic memoization without manual `useMemo` or `useCallback` boilerplate.
* **Interactive Fit Finder & Size Calculator:** Unit conversion (inches/cm), real-time size recommendations (XS–4XL), personalized contouring advice, and full international sizing charts.
* **Dynamic Cart Drawer:** Live free shipping threshold progress bar, smart upsell recommendations, promo code engine (`ROVELLE10`, `VIP15`), and persistent state.
* **Regional & Currency Support:** Instant switcher between USD ($), Ghana Cedis (GH₵), and GBP (£).
* **Multi-Channel Checkout Simulator:** Supports Ghana Mobile Money (MTN MoMo, Telecel Cash), Credit/Debit Card, and Cash on Delivery (COD).
* **14-Day Fit Guarantee Assurance:** Built-in messaging, trust badges, and hassle-free size exchange promises throughout the buyer journey.

---

## 🛠️ Tech Stack & Configuration

* **Framework:** React 19 + Vite 6
* **Language:** TypeScript 5.7 (strict mode)
* **Optimization:** `babel-plugin-react-compiler` (target: React 19)
* **Linting:** ESLint 9 (Flat Config) + `eslint-plugin-react-compiler` + `typescript-eslint`
* **Styling:** Tailwind CSS + PostCSS + Autoprefixer
* **Icons:** Lucide React
